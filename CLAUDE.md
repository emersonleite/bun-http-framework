# Regras do projeto

## Git

- **Nunca faça commit sem autorização expressa do usuário.** Uma autorização vale só para o pedido em que foi dada: um "pode commitar" anterior não autoriza commits de mudanças feitas depois. Ao terminar uma alteração, deixe-a no working tree e pergunte se pode commitar.
- Nunca faça push sem pedido explícito.
- Mensagens de commit em inglês.

## Documentação

- **Toda mudança no sistema deve ser acompanhada de uma revisão das docs.** Ao terminar uma alteração, verifique se `README.md`, `EXEMPLOS-ROTAS.md`, `PLANO-FUTURO-PAN.md` e `docs/` ainda refletem o código (assinaturas, exemplos, tabela de estrutura, itens do plano) e atualize o que ficou desatualizado na mesma entrega.
- Se nada precisar mudar, diga isso explicitamente ao final.
